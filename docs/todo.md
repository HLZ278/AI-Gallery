一、优先建议（小改动、体验提升明显）
1. 文档与产品信息同步
当前代码已到 v1.7.0，但 USER_GUIDE.md、README.md 仍偏早期版本，缺少：

文生图、AI 编辑、局域网传输
向量索引补建/重建
实体识别 v1.1（IP / 角色 / 作品）
预览缩放（滚轮、+/-）
三种搜索模式的区别与前置条件
另外 electron-builder.yml 里产品名还是 YourPicture，与界面「AI图库」不一致，打包时建议统一。

2. 搜索体验小缺口
问题	说明
筛选不自动搜索
改日期/类型/图库后要手动点「搜索」
只有第一页 120 条
后端支持分页，UI 无「加载更多」
零结果提示不准
有图库但搜不到时，仍显示「请先导入图片」
向量模式无前置提示
向量索引关闭时按钮仍可点，搜完才报错
3. 详情面板可再补几项
已有 IP/角色/作品展示，还可以加：

主色调（colors 字段已有，未展示）
分析时间 / 模型 / 提示词版本（方便判断要不要重新分析）
点击标签直接搜索（点「蔡徐坤」填入搜索框）
分析失败原因（目前 failed 只有状态，无具体错误）
4. 设置页与配置脱节
default.config.json 里很多项设置页没暴露，例如：

分析提示词版本（promptVersion 1.0 → 1.1 需手动改 config）
文生图 availableSizes、negativePrompt
AI 编辑超时、尺寸限制等
ui.gridColumnMinWidth 配置了但网格仍硬编码 160px
建议至少把 提示词版本 和 API 连通性测试 做到设置里，日常维护会轻松很多。

5. 空状态与错误反馈
多处仍用 alert()，与整体 Apple 风格不太一致：

图库扫描失败无提示（LibraryPage）
应用初始化失败无错误页（useAppInit）
缩略图状态点悬停显示英文 pending/failed，可改成中文
二、工作流串联（中等工作量）
6. 搜索 → AI 编辑 打通
现在要在 AI 编辑里重新选图；搜索页选中图片后，可加：

右键「发送到 AI 编辑」
或详情面板快捷按钮
7. AI 编辑源图列表限制
侧栏只加载前 120 张，大图库选源图不方便，需要分页或搜索/筛选（与下面虚拟滚动可一起做）。

8. 文生图 / AI 编辑会话管理
Store 里已有重置逻辑，但页面无「清空历史」按钮；长聊天后会话会很长。

9. 局域网设置即时生效提示
改端口/开关后需点「保存设置」才生效，界面上可加一句说明，或保存后自动重启 LAN 服务。

五、建议实施顺序
若只想再 polish 一轮，我建议按这个顺序：

1. 文档同步（USER_GUIDE + README + 打包名统一）     ← 半天
2. 搜索：零结果提示 + 向量模式禁用态 + 加载更多      ← 1天
3. 详情面板：标签点击搜索 + 分析元数据 + colors      ← 半天
4. 设置：提示词版本 + API 测试 + 保存后刷新 stats    ← 半天
5. 搜索 → AI 编辑 入口                              ← 半天
6. 错误反馈统一（替换 alert、扫描失败提示）           ← 1天
7. 虚拟滚动                                         ← 2–3天
