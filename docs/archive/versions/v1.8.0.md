# v1.8.0

**发布日期**：2026-05-28

## 本地端侧分析与向量索引

- 默认使用本机 ONNX（`@huggingface/transformers` 4.x）进行图片语义描述与 BGE 中文向量建索引，导入/扫描后零 API token
- 模型清单见 `config/local-models.json`；下载缓存至**安装目录** `models/`（启动时自动从 `%APPDATA%/YourPicture/models` 迁移）
- 本地描述：**Qwen3-VL 2B**（默认推荐）、**Qwen2.5-VL 3B**；已移除 Qwen2-VL 2B
- 桌面端推理统一映射为 ONNX **CPU**（`wasm`/`dml`/`auto` 配置项兼容）；Qwen VL 在 DirectML 上 generate 不稳定
- 支持单张/批量「云端增强分析」，覆盖本地结果并自动重建向量
- 设置页：默认分析模式、向量提供方、模型下载与管理、推理设备

## 配置新增

- `analysis.defaultMode`、`analysis.localCaptionModelId`、`analysis.localConcurrency`、`analysis.fallbackToCloudWhenLocalUnavailable`
- `embedding.provider`、`embedding.localModelId`
- `localModels.remoteHost`、`hfToken`、`ignoreEnvHfToken`、`inferenceDevice`

## 分析结果标识

- `model_name` 前缀：`local/{modelId}` 或 `cloud/{llm.model}`
- 本地 caption 输出 JSON（含 markdown 代码块、中文字段名）解析至各分析字段
