# v1.8.2

**发布日期**：2026-05-29

## DirectML GPU 加速

- Windows 下 `auto` / `dml` 推理设备启用 **DirectML**（AMD / Intel 独显与核显）
- Qwen VL 加载与推理失败时自动回退 **ONNX CPU**；BGE 向量模型同样支持 DML
- 设置页更新设备选项说明；默认 `inferenceDevice: auto`

## 图库与分析工作流

- 扫描目录后 **不再自动分析**，需点击「开始分析 (N)」
- 图库卡片展示 **正在分析** 实时数量
- 文件更新 / 原地修改触发重新分析；ImportHelper 返回 action 语义

## 体验优化

- 跟随系统主题、搜索页图库同步、自定义 ConfirmDialog
- 图库扫描细粒度进度、分析完成后自动刷新统计
