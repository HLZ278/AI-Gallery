# v1.8.1

**发布日期**：2026-05-28

## 推理子进程稳定化

- `LocalInferenceBridge`：fork `localInferenceWorker`，RPC 协议（init / caption / embed / download）
- 主进程 `LocalModelService` 改为门面；预处理（sharp/ffmpeg）仍在主进程，ONNX 在子进程
- 修复启动死锁：`sendRequest` 与 `ensureStarted` 分离，`doStart` 不再经 `request()` 间接调用 `start()`
- 子进程崩溃自动重启；应用退出时 `shutdown` 终止 worker

## 构建

- `electron.vite` 增加 `localInferenceWorker` 入口，产物 `out/main/localInferenceWorker.js`

## 依赖上一版 (1.8.0)

- Qwen3-VL 2B 默认、模型目录 `安装目录/models/`、CPU 推理映射等见 [v1.8.0.md](v1.8.0.md)
