# YourPicture v1.4.0

**日期**: 2026-05-23

## 预览体验升级 + 视频 AI 分析

### 单张预览（Apple 风格）

- 沉浸式深色预览、毛玻璃工具栏
- 旋转（顺/逆时针 90°）、全屏（按钮 / F 键 / 双击）
- 左右切换搜索结果（箭头 / ← →）
- 预览内右键：复制文件、打开文件所在位置
- 修复右上角关闭按钮偶发无法点击

### 视频预览

- 自定义播放器：拖动进度、播放/暂停、倍速（0.5x–2x）

### 多图对比

- 搜索页 / AI 助手页：选中图片后可选 1–6 张滑动窗口对比
- 左右按钮 / ← → 将窗口整体后移或前移一张
- 支持全屏对比

### 视频 AI 分析

- ffmpeg 抽关键帧 + 多帧视觉 API
- 提示词 `prompts/video_analysis_v1.json`
