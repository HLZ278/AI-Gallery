# v1.8.3

**发布日期**：2026-05-29

## AMD GPU 加速（Ollama + Vulkan）

- 新增 **AMD GPU（Ollama + Vulkan）** 推理路径：视觉分析走本地 Ollama HTTP，向量仍用 BGE ONNX（CPU）
- `OllamaRuntimeService`：安装/启动 Ollama、拉取视觉模型；模型目录 `ollama-models/` 与 ONNX `models/` 分离
- 设置页：Ollama 环境配置与视觉模型下载拆分；`OllamaSetupAction` / `ModelDownloadAction` 联动
- 默认视觉模型改为 **Qwen3-VL 2B Instruct**（`qwen3-vl:2b-instruct`），旧 tag 自动映射

## 推理设备简化

- 移除 DirectML / auto 路径；`inferenceDevice` 仅 **wasm（CPU）** / **cuda（NVIDIA）** / **amd（Ollama）**
- GPU 加载失败 **显式报错**，不再静默回退 CPU（配置见 `config/inference-devices.json`）

## 分析结果解析增强

- 模型输出 markdown 代码块、JSON 截断、OCR 重复幻觉：增强 `AnalysisPayloadMapper` 容错
- `AnalysisTextSanitizer` + `config/analysis-limits.json` 限制 OCR/文本字段长度
- 解析失败时不再把整段 JSON 塞入「场景/描述」；详情面板长文本折叠
