# AI图库 用户使用指南

> 面向零基础 Windows 用户  
> 产品名 **AI图库**，数据目录 `%APPDATA%/YourPicture`（历史兼容名）

## 1. 安装准备

### 需要安装的软件

1. **Node.js 20 LTS** — 从 [nodejs.org](https://nodejs.org) 下载安装
2. **Git**（可选）— 用于获取源码

### 首次运行（开发者模式）

```powershell
cd D:\AndroidProject\PictureSearch
npm install
npm run dev
```

### 打包为 exe（可选）

```powershell
npm run pack
```

安装包输出在 `release` 目录。

---

## 2. 首次配置

1. 打开应用，点击左侧 **设置**
2. 填写 **API Key**（阿里云 DashScope 控制台获取）
3. **Base URL** 保持默认即可（OpenAI 兼容模式）
4. **Model** 需填写支持「看图」的视觉模型，例如：
   - `qwen-vl-max`（推荐）
   - `qwen-vl-plus`
5. 点击 **测试 API 连接** 验证
6. 分析提示词会自动使用最新版本（升级应用后请对旧图重新分析）
7. 点击 **保存设置**

---

## 3. 建立图库

1. 点击 **图库** → **添加图库**
2. 选择存放照片的文件夹
3. 点击 **扫描目录**，应用会导入并启动 AI 分析
4. 应用会自动监控图库目录变更（新增/删除文件）

---

## 4. 导入图片

1. 点击 **导入**
2. 选择目标图库
3. 点击 **选择文件并导入**
4. 等待进度条完成

---

## 5. 搜索图片

### 三种搜索模式

| 模式 | 说明 | 前提 |
|------|------|------|
| **关键词** | 精确匹配描述、人物、标签、OCR、GPS 等 | 图片已完成分析 |
| **向量语义** | 模糊描述按相似度匹配 | 设置中启用并建立向量索引 |
| **AI 智能** | 大模型阅读全库文字详情推理 | 已完成分析，消耗 Token 较多 |

### 操作技巧

- 修改日期/类型/图库筛选后会**自动搜索**
- 结果超过 120 条时可点 **加载更多**
- 点击详情中的标签可**一键搜索**
- 右键图片可 **发送到 AI 编辑**
- 按 **?** 查看快捷键帮助，**Ctrl+F** 聚焦搜索框

### 预览与多图对比

**单张预览**：双击缩略图

| 操作 | 方式 |
|------|------|
| 关闭 | Esc、右上角 ×、点击空白处 |
| 上一张 / 下一张 | 左右按钮或 ← → |
| 放大 / 缩小 / 重置 | 滚轮、工具栏按钮、+ / - / 0 |
| 旋转 | 工具栏、R / Shift+R |
| 全屏 | 底部按钮、F 键、双击图片 |
| 视频播放/暂停 | 空格、点击画面 |

**多图对比**：

1. 单击选中一张图片
2. 点击 **多图对比** 选择 1–6 张窗口大小
3. 使用 ← → 平移窗口

---

## 6. 文生图

1. 点击 **文生图**
2. 选择目标图库与尺寸
3. 输入描述并发送
4. 预览后选择 **接受并保存** 或 **拒绝**
5. 可点击 **清空会话** 重置聊天记录

---

## 7. AI 图片编辑

1. 点击 **AI 编辑** 或从搜索页右键发送
2. 从图库选择 1~3 张**静态图片**（照片/实况/全景/连拍）
3. 输入编辑指令
4. 选择 **入库**、**覆盖原图** 或 **拒绝**

---

## 8. 向量索引

在 **设置 → 向量语义搜索**：

- **补建向量索引**：仅处理尚未索引的图片
- **重新建立向量索引**：清空后全量重建（换模型时使用）

---

## 9. 局域网传输

1. 在 **设置** 中启用局域网服务并 **保存设置**
2. 在 **导入** 页查看链接与二维码
3. 搜索页右键可 **局域网分享** 单图

---

## 10. 常见问题

### Q: 分析一直 pending？

- 检查 API Key 与视觉模型
- 侧边栏可 **重试全部失败项**

### Q: 搜不到人名/IP？

- 升级应用后 **重新分析** 以使用最新提示词
- 建立/重建向量索引后用向量语义搜索

### Q: API Key 安全吗？

Key 仅保存在本机 `%APPDATA%/YourPicture/config.json`。

---

## 11. 推荐使用流程

```
配置 API → 添加图库 → 扫描/导入 → 等待分析 → 建立向量索引 → 搜索浏览
```

祝您使用愉快！
