# AI图库 用户使用指南

> 面向零基础 Windows 用户

## 1. 安装准备

### 需要安装的软件

1. **Node.js 20 LTS** — 从 [nodejs.org](https://nodejs.org) 下载安装
2. **Git**（可选）— 用于获取源码

### 首次运行（开发者模式）

1. 打开 PowerShell，进入项目目录：
   ```powershell
   cd D:\AndroidProject\PictureSearch
   ```
2. 安装依赖：
   ```powershell
   npm install
   ```
3. 启动应用：
   ```powershell
   npm run dev
   ```

### 打包为 exe（可选）

```powershell
npm run pack
```

安装包输出在 `release` 目录。

---

## 2. 首次配置

1. 打开应用，点击左侧 **设置**
2. 填写 **API Key**（阿里云 DashScope 控制台获取）
3. **Base URL** 保持默认即可（OpenAI 兼容模式）
4. **Model** 需填写支持「看图」的视觉模型，例如：
   - `qwen-vl-max`
   - `qwen-vl-plus`
   > 注意：纯文本模型无法分析图片
5. 点击 **保存设置**

---

## 3. 建立图库

1. 点击 **图库** → **添加图库**
2. 选择存放照片的文件夹（如「图片」或手机同步目录）
3. 点击 **扫描目录**，应用会：
   - 导入所有图片/视频
   - 启动 AI 逐张分析

---

## 4. 导入图片

1. 点击 **导入**
2. 选择目标图库
3. 点击 **选择文件并导入**，可一次选多张
4. 等待进度条完成

---

## 5. 搜索图片

1. 点击 **搜索**
2. 选择搜索模式：
   - **关键词搜索**：基于索引快速匹配
   - **向量语义**：模糊描述即可匹配（需先建立向量索引）
   - **AI 智能搜索**：大模型阅读图库文字详情进行语义匹配（不传图片）
3. 在搜索框输入描述，例如：
   - `羽毛球`
   - `海边日落`
   - `梗图`
   - `合照`
4. 可使用筛选：
   - **日期范围**
   - **媒体类型**：照片、视频、动图、实况、全景、连拍
   - **图库**

5. 点击缩略图查看右侧详情，包含单张 AI 分析结果。

### 预览与多图对比

**单张预览**：双击缩略图

| 操作 | 方式 |
|------|------|
| 关闭 | Esc、右上角 ×、点击空白处 |
| 上一张 / 下一张 | 左右按钮或 ← → |
| 旋转 | 底部工具栏（仅图片） |
| 全屏 | 底部按钮、F 键、双击图片 |
| 视频播放/暂停 | 空格、点击画面 |
| 视频倍速 / 进度 | 底部控制条拖动 |
| 复制 / 打开位置 | 预览内右键 |

**多图对比**：

1. 在搜索结果中**单击**选中一张图片
2. 网格上方出现「多图对比」，点击 **1–6** 选择同时预览张数
3. 使用左右按钮或 ← → **平移窗口**（每次移动一张）
4. 底部可进入全屏对比

## 6. 常见问题

### Q: 分析一直 pending？

- 检查设置中的 API Key 是否正确
- 确认 Model 支持视觉（图片）输入
- 查看网络是否能访问 Base URL

### Q: 搜索不到中文关键词？

应用会使用全文索引 + 模糊匹配，确保图片已完成 AI 分析（绿点状态）。

### Q: API Key 安全吗？

Key 仅保存在本机 `%APPDATA%/YourPicture/config.json`，不会上传到任何服务器（除您配置的 LLM API）。

---

## 7. 推荐使用流程

```
配置 API → 添加图库 → 扫描/导入 → 等待分析 → 搜索浏览
```
