# AI图库 用户使用指南

> 面向零基础 Windows 用户  
> 产品名 **AI图库**，数据目录 `%APPDATA%/YourPicture`（历史兼容名）

## 1. 安装准备

### 需要安装的软件

1. **Node.js 20 LTS** — 从 [nodejs.org](https://nodejs.org) 下载安装
2. **Git**（可选）— 用于获取源码

### 首次运行（开发者模式）

```powershell
cd D:\AndroidProject\PictureSearch
npm install
npm run dev
```

### 打包为 exe（可选）

```powershell
npm run pack
```

安装包输出在 `release` 目录。

---

## 2. 首次配置

### 本地分析（推荐，省 token）

1. 打开 **设置** → **本地端侧分析**
2. 选择 **本地推理设备**：
   - **纯 CPU**：下载 ONNX 模型（见下），适合无独显或 NVIDIA 不可用环境
   - **CUDA（NVIDIA GPU）**：Linux + CUDA 12 环境
   - **AMD GPU（Ollama + Vulkan）**：Windows AMD 显卡；先 **配置 Ollama 运行环境**，再 **下载视觉模型**（Instruct 版，如 Qwen3-VL 2B Instruct）
3. 若无法访问 Hugging Face，在 **模型下载源** 填写 `https://hf-mirror.com`（ONNX 模型**无需 HF 账号**）
4. **纯 CPU / CUDA** 路径：点击 **下载** Qwen3-VL 与 BGE 向量模型
5. **本地并发** 建议 1（3B 模型或 Ollama 首帧较慢）
6. 保持 **默认分析模式** 为「本地」、**向量提供方** 为「本地」
7. 点击 **保存设置**

本地提问与 `prompts/image_analysis_*.json` 的 `local_caption_instruction` 对齐；模型输出 JSON 会解析到描述、人物、场景等字段。  
**AMD 模式**下 ONNX 仅用于 BGE 向量，视觉分析由 Ollama 完成，模型分别存放在 `models/` 与 `ollama-models/`。

### 云端增强（可选）

1. 在 **大模型 API** 填写 **API Key**（阿里云 DashScope）
2. **Model** 使用支持视觉的模型（如 `qwen3.5-plus`）
3. 点击 **测试 API 连接**
4. 对需要识别人物/IP/梗的图片，在详情面板使用 **云端增强分析**，或多选后 **批量云端增强**

分析提示词会自动使用最新版本；切换向量模型后请在设置中 **重新建立向量索引**。

---

## 3. 建立图库

1. 点击 **图库** → **添加图库**
2. 选择存放照片的文件夹
3. 点击 **扫描目录** 导入媒体
4. 扫描完成后点击 **开始分析 (N)** 启动 AI 分析（不会自动开始）
5. 应用会自动监控图库目录变更（新增/修改/删除文件）

---

## 4. 导入图片

1. 点击 **导入**
2. 选择目标图库
3. 点击 **选择文件并导入**
4. 等待进度条完成

---

## 5. 搜索图片

### 三种搜索模式

| 模式 | 说明 | 前提 |
|------|------|------|
| **关键词** | 精确匹配描述、人物、标签、OCR、GPS 等 | 图片已完成分析 |
| **向量语义** | 模糊描述按相似度匹配 | 设置中启用并建立向量索引 |
| **AI 智能** | 大模型阅读全库文字详情推理 | 已完成分析，消耗 Token 较多 |

### 操作技巧

- 修改日期/类型/图库筛选后会**自动搜索**
- 结果超过 120 条时可点 **加载更多**
- 点击详情中的标签可**一键搜索**
- 右键图片可 **发送到 AI 编辑**
- 按 **?** 查看快捷键帮助，**Ctrl+F** 聚焦搜索框

### 预览与多图对比

**单张预览**：双击缩略图

| 操作 | 方式 |
|------|------|
| 关闭 | Esc、右上角 ×、点击空白处 |
| 上一张 / 下一张 | 左右按钮或 ← → |
| 放大 / 缩小 / 重置 | 滚轮、工具栏按钮、+ / - / 0 |
| 旋转 | 工具栏、R / Shift+R |
| 全屏 | 底部按钮、F 键、双击图片 |
| 视频播放/暂停 | 空格、点击画面 |

**多图对比**：

1. 单击选中一张图片
2. 点击 **多图对比** 选择 1–6 张窗口大小
3. 使用 ← → 平移窗口

---

## 6. 文生图

1. 点击 **文生图**
2. 选择目标图库与尺寸
3. 输入描述并发送
4. 预览后选择 **接受并保存** 或 **拒绝**
5. 可点击 **清空会话** 重置聊天记录

---

## 7. AI 图片编辑

1. 点击 **AI 编辑** 或从搜索页右键发送
2. 从图库选择 1~3 张**静态图片**（照片/实况/全景/连拍）
3. 输入编辑指令
4. 选择 **入库**、**覆盖原图** 或 **拒绝**

---

## 8. 向量索引

在 **设置 → 向量语义搜索**：

- **补建向量索引**：仅处理尚未索引的图片
- **重新建立向量索引**：清空后全量重建（换模型时使用）

---

## 9. 局域网传输

1. 在 **设置** 中启用局域网服务并 **保存设置**
2. 在 **导入** 页查看链接与二维码
3. 搜索页右键可 **局域网分享** 单图

---

## 10. 常见问题

### Q: 分析一直 pending 或没有进展？

- **本地 ONNX**：确认描述模型与 BGE 已下载；查看终端 `[LocalInference]` 日志
- **AMD/Ollama**：确认 Ollama 已配置、视觉模型为 **Instruct** 版且已下载；查看 `[Ollama]` / `[AnalysisParse]` 日志
- **云端回退**：勾选「本地不可用时回退云端」并填写 API Key
- 侧边栏可 **重试全部失败项**；单张可用 **本地重新分析**

### Q: 描述里出现整段 JSON 或 OCR 特别长？

- 升级至 v1.8.3+ 后 **重新分析** 该图；新版本会自动解析 JSON 并截断异常 OCR

### Q: 搜不到人名/IP？

- 升级应用后 **重新分析** 以使用最新提示词
- 建立/重建向量索引后用向量语义搜索

### Q: API Key 安全吗？

Key 仅保存在本机 `%APPDATA%/YourPicture/config.json`。

```
添加图库 → 扫描 → 开始分析 → 建立向量索引 → 搜索浏览
（可选：详情面板「云端增强分析」）
```
